Juntar backups

sem apagar nada

Escolha um ou mais arquivos de backup (do celular, do computador…). O que é novo entra, o que foi editado fica com a versão mais recente e o que foi excluído continua excluído. Juntar o mesmo arquivo duas vezes não duplica nada.

Como usar no celular e no computador

  1. No computador, toque em Baixar backup.
  2. No celular, toque em Baixar backup (ou Enviar e mande para você no WhatsApp ou Drive).
  3. No computador, use Juntar backups e escolha o arquivo do celular. Agora o computador tem tudo dos dois.
  4. Baixe um backup novo no computador e junte no celular, para o celular também ficar completo.

Os dados ficam guardados no navegador de cada aparelho. Se você limpar os dados do navegador ou trocar de navegador, eles somem dali, então baixe um backup de vez em quando.
